# Aphrodite v0.2.7 — release notes

A section with one implementation and many layouts is a set of cards, not one card and a row of chips.

## What's new since v0.2.6

**Each layout is a card you can add**
- Hero, and the other sections that exist as one implementation with several layouts, showed a single preview. The other layouts were chips and a menu, so the page you would get was the one layout currently selected.
- Those layouts are now cards. The card's name is the layout, and Add puts that layout on the page.
- A kind with several implementations, such as Button, stays a comparison of one variation across design systems. Filtering that kind down to one system does not turn its variations into a gallery.
