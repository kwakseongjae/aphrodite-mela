# Aphrodite 5분 시연 · Astra(computer use) 인수인계 프롬프트

아래 블록을 그대로 Astra에게 전달한다. 앱은 Aphrodite v0.1.3(한국어 UI, 창 1500×960)이며 macOS 화면을 computer use로 조작한다.

---

당신은 지금 Mac에서 열려 있는 **Aphrodite** 데스크톱 앱을 computer use로 조작해 관객 앞에서 5분 시연을 한다. 목표는 "레퍼런스 → 3안 → 선택 → 분위기 입히기 → 에이전트 위임 → 개발 핸드오프 → 승인·내보내기"까지 전 과정을 끊김 없이 보여주는 것이다. 말은 짧게, 손은 빠르게. 각 단계마다 한 줄만 설명하고 바로 다음 동작으로 넘어간다.

## 절대 규칙
1. 매 클릭 전에 Aphrodite 창이 최전면인지 확인한다. 다른 앱이 앞에 있으면 Aphrodite를 먼저 클릭해 활성화한다. 다른 앱에는 아무것도 입력하지 않는다.
2. 화면 맨 아래 상태줄(페이지 · 컴포넌트 수 · 선택 · 디자인 시스템 · 초안/승인 · 저장됨)이 진실이다. 동작 후 상태줄이 바뀌었는지로 성공을 판단한다.
3. 모달이 떠서 막히면 Esc. 토스트(초록 말풍선)는 무시하고 진행한다.
4. **에이전트 모드 중에는 "방향 승인"을 절대 누르지 않는다.** 승인은 제어를 회수한 뒤 사람 몫으로 남긴다.
5. 파일 저장 대화상자가 열리면 데스크톱에 저장하거나 취소한다. 다른 폴더를 뒤지지 않는다.
6. 무엇이 10초 이상 반응이 없으면 한 번만 기다리고, 그래도 없으면 해당 단계를 건너뛰고 다음으로 간다.

## 단축키 (텍스트 입력 중이 아닐 때, 모달이 없을 때)
- V 선택 · H 손 · A 컴포넌트 추가 · F 새 프레임 · R 레퍼런스 · G Get Vibe · P 미리보기
- 1 디자인 모드 · 2 개발 모드 · 3 에이전트 모드
- ⌘K 또는 / 검색 팔레트 · ⇧1 전체 보기 · ⇧2 현재 프레임 맞춤 · ⌘0 100% · Space+드래그 이동 · Esc 닫기 · ⌘Z 실행 취소

## 시나리오 (총 5분)

**0:00 준비 (10초)**
- 홈 화면이어야 한다. 환영 시트가 떠 있으면 "나중에"를 누른다. 에디터가 열려 있으면 왼쪽 위 "aphrodite" 워드마크를 눌러 홈으로 간다.
- 말: "로컬 우선 디자인 워크벤치 Aphrodite입니다. 계정도 클라우드도 없습니다."

**0:10 새 프로젝트 (20초)**
- "새 프로젝트" 버튼 → 이름 입력란에 `Demo · 빛공방` → "프로젝트 만들기"(진한 버튼).
- 확인: 에디터가 열리고 공간 위에 빈 프레임 `Home` 하나, 하단 가운데에 독(도구 7개 + 디자인/개발/에이전트).
- 말: "페이지는 열린 공간 위의 프레임입니다. 피그마처럼 움직이지만, 안에 든 건 실제 컴포넌트입니다."

**0:30 레퍼런스 → 3안 (70초)**
- R 키 → 레퍼런스 모달 → "샘플 레퍼런스 써보기" → 이미지가 뜨면 "레퍼런스 분석".
- 분석 모달(단서: 텍스트 줄, 색, 영역)이 뜨면 "3안 비교".
- 비교 모달에 3안이 나란히 뜬다. 하단의 "3안 모두 공간에 펼치기"를 누른다. (이 버튼이 없으면 "1안 사용"으로 대체하고 다음 단계로.)
- 확인: 캔버스가 전체 보기로 바뀌고 원본 프레임 아래에 점선 금색 테두리의 제안 프레임 3개(라벨에 "제안 · …")가 깔린다.
- 말: "레퍼런스는 이 Mac에서만 읽습니다. Apple Vision OCR과 픽셀 분석으로 단서를 뽑고, 같은 컴포넌트로 배치만 다른 3안을 공간에 펼칩니다. 모델 생성이 아니라 정직한 변형입니다."

**1:40 방향 선택 (20초)**
- 첫 번째 제안 프레임의 라벨에 있는 "이 방향으로"를 누른다.
- 확인: 제안 프레임 3개가 사라지고 원본 `Home` 프레임에 그 구성이 들어간다. 카메라가 그 프레임으로 맞춰진다. 안 맞으면 ⇧2.
- 말: "결정은 사람이 합니다. 나머지 두 안은 깔끔하게 정리됩니다."

**2:00 Get Vibe (40초)**
- G 키 → Get Vibe 폼. 팩·언어는 기본값 그대로 두고 폼의 진한 제출 버튼을 누른다.
- 미리보기(바뀌는 문구·이미지 목록)가 뜨면 "이 초안 적용 · 실행 취소 가능"을 누른다. (바뀔 것이 없다는 안내가 나오면 그 안의 "기존 내용을 교체해 다시 미리보기" 버튼을 누른 뒤 적용한다.)
- 확인: 프레임의 문구와 이미지가 브랜드 톤으로 채워지고 상태줄의 저장 표시가 "저장됨"으로 돌아온다.
- 말: "샘플 문구와 이미지도 로컬 팩입니다. 적용 전에 무엇이 바뀌는지 먼저 보여주고, 언제든 실행 취소됩니다."

**2:40 한 줄 편집 (20초)**
- 프레임 맨 위 히어로 블록을 클릭한다. 오른쪽 인스펙터의 제목 입력란을 클릭해 내용을 지우고 `빛으로 완성하는 공간`을 입력한다.
- 확인: 캔버스의 히어로 제목이 즉시 바뀐다.
- 말: "실제 DOM이라 바로 반영됩니다. 이 화면 그대로 에이전트도 조작할 수 있습니다."

**3:00 에이전트 위임 (60초)**
- 3 키 → "에이전트에게 화면 맡기기" 폼. 조작 주체 `Astra · computer use`, 목표 `히어로 아래에 특징 섹션을 추가하고 문구를 다듬어 주세요`, 범위 드롭다운에서 "이 프레임만", 체크박스는 그대로 → "에이전트 모드 시작".
- 확인: 상단에 노란 배너("에이전트가 조작 중 · Astra …"), 오른쪽 인스펙터가 에이전트 콘솔(범위, 승인 잠김, 타임라인)로 바뀐다.
- 이제 에이전트로서 작업한다: ⌘K → `특징` 입력 → 목록의 "특징 추가" Enter. 이어서 ⌘K → `CTA` 입력 → "CTA 추가" Enter.
- 확인: 프레임에 섹션이 붙고 콘솔 타임라인에 `catalog:add` 영수증이 최신순으로 쌓인다. 배너의 기록 수가 올라간다.
- 일부러 한 번: 오른쪽 아래 "방향 승인"에 마우스를 올리고 **누르지 않은 채** 말한다. "승인은 잠겨 있습니다. 에이전트가 눌러도 거부됩니다."
- 콘솔의 "제어 회수"를 누른다. 확인: 배너가 사라지고 디자인 모드로 돌아오며 실행 기록이 남았다는 토스트.
- 말: "위임은 계약이자 기록입니다. 범위를 정하고, 모든 편집이 영수증으로 남고, 언제든 되찾습니다."

**4:00 개발 핸드오프 (30초)**
- 2 키 → 개발 모드. 히어로 블록을 클릭한다.
- 확인: 인스펙터가 읽기 전용 핸드오프(컴포넌트 식별자, CSS 토큰, 마크업, 노드, DESIGN.md)로 바뀐다. "마크업 복사" 또는 "페이지 HTML 복사"를 한 번 누른다(토스트 "복사했습니다").
- 1 키로 디자인 모드 복귀.
- 말: "개발자에게는 같은 화면이 그대로 계약서가 됩니다."

**4:30 승인과 내보내기 (30초)**
- 오른쪽 아래 "방향 승인"을 누른다. 확인: 토스트 "방향이 승인됐습니다", 상태줄이 "승인됨"으로 바뀐다.
- 상단 오른쪽 진한 버튼 "내보내기"를 누른다. 확인: 내보내기 모달이 열린다.
- "핸드오프 ZIP 내려받기"를 누른다. 저장 대화상자가 뜨면 데스크톱에 저장(또는 취소).
- 말: "PROMPT.md, DESIGN.md, tokens.json, 렌더된 HTML, 프로젝트 파일. Codex나 Claude Code가 그대로 구현합니다. 만들기 전에, 방향부터."

## 끝난 뒤
- Esc로 모달을 닫고 ⇧1로 전체 보기 상태에서 멈춘다. 관객 질문을 받는다.
- 시연용 프로젝트는 그대로 두어도 된다. 홈에서 우클릭 → "삭제…"로 지울 수 있다.

## 문제가 생기면
- 화면이 비어 보이면: Esc → ⇧1.
- 프레임이 안 보이면: 팔레트(⌘K)에서 "모든 프레임 보기".
- 한글 입력이 이상하면: 입력란을 클릭한 뒤 입력 소스를 ABC로 바꿔 영문으로 입력해도 시연에 지장 없다. 제목은 `Light, made meaningful`, 프로젝트명은 `Demo Light Atelier`로 대체한다.
- 무엇이든 되돌리려면 ⌘Z.
