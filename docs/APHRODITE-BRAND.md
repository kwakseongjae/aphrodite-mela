# Aphrodite brand proposal v1

Concept: Shape it together. A deliberate studio where an agent assembles and a human chooses the direction. These are project design decisions, not external brand observations.

Palette: Pearl #FBF8F5 (studio background), Ink #252330 (primary text), Coral #A83C50 (action/identity), Lilac #D6B8DD (decorative supporting accent). Coral/white is for readable actions; lilac is not a primary text color.

Logo: rounded A outline with a separate pearl dot. `public/brand/aphrodite-mark.svg` is the editable source. Keep a clear zone of one pearl diameter; use at least 24px. Wordmark remains live text, not baked into the symbol.

Mascot: Pearl, a small pearl face in a scallop shell carrying an assembly block. `public/brand/pearl-mascot.svg` is an original code-native vector, not an image-model output. Use for onboarding, help and empty states. Never cover the canvas, selection handles, approval controls or error details. No animation required; respect reduced motion if added.

Voice: calm, precise, collaborative. '검토 요청' rather than '완벽하게 완성'. State exactly what was changed, what remains unknown, and whether a model was called. Never fake user approval or progress.

The workbench identity is separate from project design tokens. This increment updates topbar identity and shared action variables; not every legacy green style has been migrated. Full theme audit and owner approval remain before beta. No trademark clearance is claimed.
