# Bringing HTML onto a board

A pasted document or dropped HTML file becomes an ordinary free page. Its title supplies the page name, followed by the filename or the screen’s numbered default. A numeric viewport width uses the same 240–3,200 pixel range as an agent’s page. Other viewports use the 1,440 pixel desktop preset. For bytes, a byte-order mark takes precedence over the HTML meta charset. The fallback is UTF-8, with unreadable bytes replaced.

A desktop file or folder handed over by the operating system can bring siblings. A folder contributes its top-level HTML and HTM files in filename order. Each frame goes beside the pages already on the board. A paste or a browser File has only its own contents.

- Images, video posters, audio, video, source elements, srcset candidates and CSS URLs can name files in the chosen folder or its subfolders. The board holds PNG, JPEG, GIF, WebP, MP4, WebM, MP3, Ogg, WAV, WOFF, WOFF2, TTF and OTF bytes under their SHA-256 hashes. Pages refer to those files as `media:<hash>`.
- Local stylesheets and scripts become inline text. A stylesheet can bring three further levels of imports. Classic deferred scripts are placed in order at the end of the body. A script or stylesheet with an integrity requirement stays external, as does a file whose text contains its HTML closing tag. JavaScript-generated requests and module dependencies stay subject to the normal page wall.
- Remote addresses stay in the source and are counted. Importing never contacts them. Absolute paths, file URLs, paths or symlinks leading out of the chosen folder and relative references under an outside base grant no access. Missing or refused references are reported by name and code.

The shell receives a five-minute grant from a native file choice, Finder open or native drop. A disk request needs that grant and a relative name. HTML, CSS and script input is bounded at 6,000,000 bytes per text file. A page and its inlined text must fit the ordinary 2,000,000 UTF-16 unit page limit. A board file of media is limited to 500 MiB. Fonts use the existing data-URL policy and the 8 MiB inline limit when drawn.

A board holds 30 pages and media items, including its hidden starter. Its existing save budget also applies. The import reports the pages that fit, each refused document, and the count and original byte size of distinct siblings used by the pages made. The entire import is one person-authored change. Undo removes the pages and their media references together. The shared file store retains the bytes for redo and for other boards that use the same files.
