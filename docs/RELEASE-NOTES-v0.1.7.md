# Aphrodite v0.1.7 — release notes

The update notice, rebuilt. Shipped so the new card can be seen the way a person will actually meet
it: an older Aphrodite noticing this version and installing it on its own.

## Download

- Apple Silicon: `Aphrodite_0.1.7_aarch64.dmg`
- Intel: `Aphrodite_0.1.7_x64.dmg`
- Signed with Developer ID and notarized. macOS 13 or later.

## What's new since v0.1.6

**The update notice says one thing and asks one thing**
- The version number is the headline, in the serif the rest of the app uses for display type, with a
  single sentence and a single button. Everything else — release notes, the disk image, skipping a
  version, turning checks off — moved behind a dots menu, so the card never asks you to choose
  between four things at once.
- **What changed is answered in the card.** The first few lines of the release notes fold out where
  you are, instead of sending you to a browser.
- While it works there is no button at all: a progress bar carries the state, and the card says it
  will reopen by itself when it is done.
- Skipping a version now says which version it is skipping.

## Known limits

- An Aphrodite older than v0.1.6 has no updater and must be replaced from the disk image once.
