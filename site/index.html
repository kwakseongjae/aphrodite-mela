Around the studio

One canvas. Three ways to work on it.

  • Your projects, on this Mac

    Home keeps every project as a card with a live preview. Favourites, archive, right-click menus, and a brand kit for the studio itself. Nothing leaves the machine.

  • Hand the screen to an agent

    Agent mode delegates the same UI to a computer-use agent with a scope you choose. Every edit is receipted, approval stays yours, and you can take control back at any time.

  • Read-only handoff for developers

    Dev mode turns the inspector into a handoff: component identity, tokens as CSS, the rendered markup, page HTML, a prompt for a coding agent. Copy what you need.

Everyone is building faster. Direction still gets lost.

A coding agent can ship a page in half an hour. It can also ship the wrong page in half an hour — wrong layout, wrong tone, a hero nobody asked for — and you find out at the end.

Prompts are a poor place to keep a design decision. Screenshots drift. Figma is a different world from the code.

Deciding should start the build — not another round of rework.

How it works

Three steps. One decision.

  1. 01

    Set the direction

    Start from a brief, or drop in a reference. On macOS, Apple Vision reads the copy and layout on-device; local pixel analysis proposes colors and image regions.

  2. 02

    Make it tangible

    Assemble with real components, not mockups. Compare three directions side by side, swap design systems, edit copy and images, check desktop and 375px mobile. Every step is undoable.

  3. 03

    Make it real

    Approve the direction and export a contract: PROMPT.md, DESIGN.md, tokens.json, the rendered HTML and a project file — everything Codex or Claude Code needs to build exactly what you approved.

What's inside

Quiet tools for a loud step.

  • Local-first

    Projects live on your Mac. No account, no cloud, no generation credits. Export files whenever you want a backup.

  • Built for agents, too

    Real DOM, named buttons, stable data-actions and keyboard paths. A computer-use agent can drive the same workbench you do.

  • Design systems as tokens

    Atelier, Karrot-inspired, Toss-inspired, Mono. Change one, every page follows. Pull explicit colors from your own DESIGN.md.

  • Reference, read on-device

    OCR with Apple Vision, color and region candidates from pixels. Nothing leaves your machine.

  • Three directions, one decision

    Honest layout variants of the same components — not generated guesses. Pick one, keep the rest.

  • Approval that means something

    Any change to text, images, system or structure clears the approval. What you export is what you saw.
