# Aphrodite brand originals

What is here is the source. Everything the product shows of the brand is built from it by `npm run brand` (scripts/build-brand.mjs).
The design and the rules are in docs/APHRODITE-BRAND.md.

## Originals (edit these, then rebuild)

| File | What |
|---|---|
| `symbol.svg`, `symbol-gold.svg` | The symbol, 48-unit square. One colour (`currentColor`) and gold #B48A32 |
| `symbol-16.svg`, `symbol-16-gold.svg` | 16 px only: the same drawing moved (-1.5, 1) so the counter, legs and crossbar each get whole pixels |
| `favicon.svg` | Gold symbol with its box centred in the 48 square |
| `symbol-paper.svg` | Symbol on a paper rounded square (corner 10.8, symbol 0.8) |
| `wordmark.svg` | "Aphrodite" as outlines (Wanted Sans 800, tracking -0.035em), currentColor, font units. No font file needed |
| `lockup.svg` | Gold symbol and wordmark in one box, set by the rule in brand.json |
| `favicon-16.png`, `favicon-32.png`, `apple-touch-icon-180.png` | Drawn by Chrome from symbol-16, favicon and symbol-paper |
| `app-icon-1024.png` | The macOS app icon: the hand and the golden apple, fitted to the grid (824 body, continuous corners, shadow) |
| `app-icon/` | `app-icon-square-1024.png` (no corners, for macOS 26 and later, where the system adds them), `app-icon-1024-nocut.png` (cuts nothing from the picture), `app-icon-shape.svg` (the body outline) |
| `icons/` | The 15 PNG sizes Tauri lists, cut from app-icon-1024.png |
| `dmg/background-base@2x.png` | The installer background (1320 x 800) with its logo box cleared; the lockup is drawn over it |
| `brand.json` | The numbers: colours, symbol box, 16 px move, wordmark units, lockup rule |

## Built from them (do not edit; `npm run brand` overwrites)

| Built file | From |
|---|---|
| src/design/logo.ts | wordmark.svg, lockup.svg |
| public/brand/apple-a-lockup.svg, site/assets/brand/apple-a-lockup.svg | lockup.svg, word in the ink #1f1e19 (files loaded through an image tag cannot read the page colour) |
| public/icon.svg, site/assets/brand/favicon.svg | favicon.svg |
| the inline logo in site/index.html | lockup.svg |
| public/brand/apple-mark.png | symbol-gold.svg, 256 px (rsvg-convert) |
| public/brand/app-icon-1024.png, src-tauri/icons/*.png, site/assets/brand/favicon-*.png, apple-touch-icon-180.png | copied |
| site/assets/brand/app-icon.png | app-icon-1024.png, 256 px (sips) |
| src-tauri/icons/icon.icns, icon.ico | app-icon-1024.png (Tauri CLI). ios/ and android/ are not rebuilt |
| src-tauri/dmg/background.png, background@2x.png, background.tiff | dmg/background-base@2x.png and lockup.svg |

`outputs.json` records the SHA-256 of every source and every file the script wrote. Text files are compared as text by tests/brand.test.ts; binaries are held to this record because their bytes depend on the tool.

## Rebuild

```
npm run brand      # needs macOS: rsvg-convert (brew install librsvg), sips, tiffutil, and the Tauri CLI from node_modules
npm test           # tests/brand.test.ts checks the result
```

The originals were drawn in the 0.3-D2 brand study and are not regenerated by this script. The wordmark outlines came from Wanted Sans Variable (SIL OFL) shaped with HarfBuzz; changing the wordmark means redoing that step and replacing wordmark.svg and lockup.svg together.
